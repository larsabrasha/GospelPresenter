# Gospel Presenter Docs Site

Landing page for [gospelpresenter.com](https://gospelpresenter.com), built with Vite and Tailwind CSS.

## Prerequisites

- [Node.js](https://nodejs.org/) (v18 or later)

## Getting Started

```bash
npm install
npm run dev
```

This starts a local development server with hot reload.

## Build for Production

```bash
npm run build
```

The output is written to the `dist/` directory. Preview the production build locally with:

```bash
npm run preview
```
